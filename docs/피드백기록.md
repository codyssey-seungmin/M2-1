# 사용자 피드백 및 개선 기록

실제 사용자 응답은 Google Sheets를 원본으로 삼습니다. 이 문서에는 익명 집계와 개선 과정만 기록하며, 응답 수나 의견을 임의로 작성하지 않습니다. 개발 중 자체 점검은 실제 사용자 피드백과 구분합니다.

## 질문과 저장 위치

앱 평가 화면은 다음 세 항목을 각각 1~5점으로 받고 개선 의견 한 가지를 필수로 받습니다.

1. 디자인이 어떠신가요?
2. 감정을 돌아보고 조절하는 데 도움이 되었나요?
3. 이 앱을 계속 사용하실 의향이 있으신가요?

동의한 응답은 Google Apps Script를 거쳐 Google Sheets에 저장됩니다. 참여 코드는 같은 브라우저의 반복 평가를 묶고, 제출 ID는 같은 평가의 재전송으로 중복 행이 생기는 것을 막습니다. 이름·이메일·일기 원문은 평가 데이터에 포함하지 않습니다.

실제 수집 결과는 [사용자 평가 결과 기록지](사용자테스트기록지.md)에 평균·분포·의견 주제별로 정리합니다.

## 실제 사용자 의견에 따른 개선

| 날짜 | 참여 코드 | 의견 요약 | 재현 여부 | 우선순위 | 조치·커밋 | 재확인 |
|---|---|---|---|---|---|---|

개선 의견을 옮길 때 개인을 알아볼 수 있는 내용은 제거합니다. 같은 참여 코드가 여러 번 평가한 경우 시간 순서의 변화는 볼 수 있지만 서로 다른 사람으로 세지 않습니다.
