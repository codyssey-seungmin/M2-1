# Mindily UI·UX 기획 및 사용자 테스트 기여 기록

## 문서 정보

- 기여자: 김다빈
- 담당 영역: 서비스 기획, UI·UX 설계, 사용자 테스트 시나리오 설계 및 외부 참여자 모집
- 문서 성격: 김다빈 팀원의 기획·테스트 기여를 확인하기 위한 산출물
- 정리 기준일: 2026-10-23

이 문서는 초기 기획 내용과 최종 앱의 차이를 구분해 기록합니다. 초기 아이디어가 모두 구현되었다고 주장하지 않으며, 실제 기능과 기술은 저장소의 최종 코드와 기능명세를 기준으로 합니다.

## 1. 서비스 및 UI·UX 기획 기여

김다빈은 Mindily를 감정을 단순히 판정하는 도구가 아니라, 사용자가 부담 없이 마음을 기록하고 짧은 회복 활동까지 이어갈 수 있는 서비스로 기획했습니다.

주요 기획 내용은 다음과 같습니다.

- 따뜻하고 편안한 감정 일기 서비스 콘셉트 제안
- PC와 모바일에서 사용할 수 있는 반응형 화면 구성 제안
- 둥근 카드, 부드러운 배경색, 명확한 주요 버튼을 중심으로 한 디자인 방향 제안
- 감정 기록에서 회복 활동과 마음 기록으로 이어지는 사용자 흐름 설계
- 자연의 소리, 호흡, 기록 회고 등 짧게 실행할 수 있는 활동 제안
- 감정 기록을 주간·월간 흐름으로 다시 확인하는 화면 제안

## 2. 초기 기획과 최종 구현의 관계

| 초기 기획 | 최종 반영 | 변경 또는 반영 내용 |
|---|---|---|
| 따뜻하고 편안한 감정 일기 콘셉트 | 반영 | 아이보리 배경, 네이비 본문, 라벤더·세이지 계열 카드와 둥근 UI로 구현 |
| PC·모바일 대응 화면 | 반영 | 넓은 화면의 사이드 영역과 모바일 중심 앱 화면을 함께 제공 |
| 감정 기록 후 회복 활동 제안 | 반영 | 감정 일기 분석 후 AI 코치 화면에서 활동을 추천 |
| 15분 중심 회복 활동 | 수정 반영 | 사용 부담을 낮추기 위해 1분·5분·10분 활동 중심으로 구성 |
| 힐링 음원 추천 | 수정 반영 | 출처와 라이선스를 확인한 빗소리·파도 음원과 브라우저 합성 바람 소리 제공 |
| 감정 흐름 확인 | 반영 | 마음 기록 화면에서 기간별 스트레스와 감정 흐름 제공 |
| 일기 최대 500자 | 수정 반영 | 최종 앱에서는 최대 1,000자로 확장 |
| Tailwind 기반 단일 HTML 구조 | 변경 | 유지보수를 위해 HTML·CSS·JavaScript 파일을 분리해 구현 |

초기 기획과 최종 구현의 차이는 개발 과정에서 기술 여건과 사용자 피드백을 반영한 결과입니다.

## 3. 사용자 테스트 시나리오 설계

김다빈은 사용자가 앱의 핵심 흐름을 짧은 시간 안에 확인할 수 있도록 다음 테스트 순서를 설계했습니다.

1. 배포된 Mindily 앱에 접속합니다.
2. 감정 일기에 문장과 스트레스 점수를 입력합니다.
3. AI 감정 분석 결과를 확인합니다.
4. 무드 미터에서 자신의 감정을 직접 선택합니다.
5. AI 코치 화면에서 추천 활동 한 가지를 확인하거나 실행합니다.
6. 앱 평가 화면에서 디자인, 감정 조절 도움, 계속 사용할 의향을 평가하고 개선 의견을 제출합니다.

참여자에게는 다음 사항을 함께 안내했습니다.

- Mindily는 의료 진단이나 치료를 제공하는 서비스가 아닙니다.
- 평가 응답은 동의한 경우에만 Google Sheets에 저장됩니다.
- 이름·연락처·개인적인 일기 내용은 개선 의견에 적지 않습니다.
- 실제 개인 경험 대신 가상의 문장으로 앱을 시험해도 됩니다.

## 4. 외부 참여자 모집 및 테스트 진행

김다빈은 팀원이 아닌 외부 성인 4명에게 테스트 절차를 안내하고 참여를 모집했습니다. 아래 표는 이름과 연락처를 제외한 익명 집계입니다.

연령대와 성별 구분은 참여 모집 담당자의 익명 운영 기록을 바탕으로 정리했으며, 앱이나 Google Sheets에서 수집한 항목은 아닙니다.

| 참여 코드 | 익명 구분 | 제출일 | 디자인 | 감정 도움 | 계속 사용할 의향 | 개선 의견 처리 |
|---|---|---|---:|---:|---:|---|
| U04 | 20대 여성 | 2026-09-28 | 3 | 4 | 4 | 파도 소리 개선 의견을 정성 분석에 포함 |
| U07 | 20대 여성 | 2026-09-29 | 3 | 3 | 2 | 글씨 굵기 개선 의견을 정성 분석에 포함 |
| U05 | 40대 여성 | 2026-09-28 | 4 | 4 | 4 | 감정 분류 개선 의견을 정성 분석에 포함 |
| U08 | 20대 남성 | 2026-09-29 | 4 | 4 | 4 | `.` 응답은 의미 해석이 불가능해 정성 분석에서 제외 |

### 집계 기준

- 위 4명은 김다빈이 모집·안내한 외부 참여자 범위입니다. 프로젝트 전체 참여자 수와 동일한 의미가 아닙니다.
- 각 참여 코드는 서로 다른 브라우저 참여자를 구분하는 가명 코드입니다.
- U04·U05·U07·U08의 점수 응답은 모두 유효한 정량 응답으로 집계합니다.
- U08은 실제 사용자의 유효한 제출이므로 참여자 수와 세 점수에는 포함합니다.
- U08의 개선 의견 `.`은 내용을 해석할 수 없어 정성 의견 분석에서만 제외합니다. 원본 응답을 다른 의견으로 수정하지 않습니다.
- 개발자 시험 응답과 팀원 응답은 실제 사용자 집계에서 제외합니다.
- 이름, 연락처, 일기 원문과 제출 ID는 이 문서에 기록하지 않습니다.

## 5. 사용자 의견과 개선 반영 연결

| 참여 코드 | 확인된 의견 | 앱 개선 방향 |
|---|---|---|
| U04 | 합성 파도 소리가 실제 파도처럼 들리지 않음 | 출처와 라이선스를 확인한 실제 파도 음원으로 교체 |
| U07 | 글씨가 조금 더 굵었으면 좋겠음 | 주요 화면 제목과 하단 메뉴 글씨의 가독성 개선 |
| U05 | 감정 선택 항목의 분류와 구분이 필요함 | 무드 미터의 감정별 색상과 분류를 더 명확하게 조정 |
| U08 | 해석 가능한 개선 의견 없음 | 점수는 정량 집계에 유지하고 정성 분석에서만 제외 |
