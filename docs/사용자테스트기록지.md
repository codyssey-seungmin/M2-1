# Mindily 사용자 평가 결과 기록지

Google Sheets의 실제 응답을 바탕으로 익명 집계 결과만 기록합니다. 이름·연락처·일기 원문·Apps Script URL은 이 문서와 GitHub에 저장하지 않습니다.

## 수집 정보

- 수집 기간: 2026년 9월 28일 ~ 2026년 9월 29일
- 배포 주소: https://yellowmug-mindily.hf.space
- 서로 다른 참여 코드: 7개
- 유효 응답: 7건
- 제외한 시험·중복 응답: 1건 (시험 1건, 중복 0건)
- 정성 분석 제외 의견: 1건 (`.`만 입력되어 의미 해석 불가)

참여 코드의 고유 개수와 전체 응답 수는 다를 수 있습니다. 제출 ID가 같은 행은 한 제출로 계산합니다.

### 집계 기준

- Google Sheets의 원본 응답은 수정하지 않습니다.
- 문장 부호나 공백만 있어 의미를 해석할 수 없는 개선 의견은 **정성 분석에서만 제외**하고 제외 사유를 별도로 기록합니다.
- 해당 행이 실제 사용자의 유효한 제출이면 세 점수는 정량 집계에 포함합니다.
- 개발자 시험 응답은 참여자 수, 응답 수, 점수, 개선 의견 분석에서 모두 제외합니다.

평균은 유효 응답 7건을 기준으로 소수 둘째 자리까지 표시했습니다. 표본이 작으므로 전체 사용자 집단의 만족도로 일반화하지 않고 이번 테스트 참여 범위의 결과로만 해석합니다.
