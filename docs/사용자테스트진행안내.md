# 실제 사용자 피드백 수집 안내

이 문서는 배포된 Mindily 앱의 사용자 평가를 진행하기 위한 운영 안내입니다. 응답 결과를 대신하지 않으며 실제 응답을 임의로 작성하지 않습니다. 이름·연락처·일기 원문은 GitHub나 테스트 기록에 올리지 않습니다.

## 수집 직전 확인

1. https://yellowmug-mindily.hf.space 를 열고 앱이 정상 표시되는지 확인합니다.
2. 가상 문장으로 일기 → 감정 분석 → AI 코치 활동 흐름을 한 번 점검합니다.
3. AI 코치 화면의 **🤗 앱 평가 부탁드려요** 버튼을 열고 평가 페이지가 표시되는지 확인합니다.
4. 시험 응답 한 건이 Google Sheets `앱 평가` 탭에 한 행만 저장되는지 확인합니다. 시험 응답은 실제 수집 전에 삭제하거나 별도로 표시합니다.
5. Google Sheets 공유 권한이 필요한 팀원으로 제한되어 있는지 확인합니다.

## 참가자에게 전달할 문구

> Mindily 감정 일기 앱을 약 5분간 사용해 주세요. 주소는 **https://yellowmug-mindily.hf.space** 입니다. 실제 개인 이야기 대신 가상의 문장을 사용해도 됩니다. 분석 결과를 확인하고 감정을 직접 고른 다음 AI 코치 활동 하나를 사용해 보세요. 마지막에 AI 코치 화면의 **🤗 앱 평가 부탁드려요** 버튼에서 디자인, 감정 조절 도움, 계속 사용할 의향을 평가하고 개선 의견을 남길 수 있습니다. 평가는 동의할 때만 Google Sheets에 저장됩니다. 이름·연락처·개인적인 일기 내용은 개선 의견에 적지 말아 주세요. 이 앱은 의료 진단 도구가 아닙니다.

이 문구는 참여자에게 직접 전달합니다. 앱이나 저장소에서 자동 발송하지 않습니다.

## 앱에서 수집하는 내용

| 항목 | 형식 |
|---|---|
| 디자인 | 1~5점 |
| 감정을 돌아보고 조절하는 데 도움 | 1~5점 |
| 계속 사용할 의향 | 1~5점 |
| 개선 의견 | 필수, 500자 이내 |
| 참여 코드 | 같은 브라우저에 자동 부여 |
| 제출 ID | 평가 한 건의 중복 저장 방지용 |

## 집계 방법

1. 실제 참여자 수는 참여 코드의 **고유 개수**로 셉니다.
2. 전체 응답 수는 유효한 응답 행 수로 셉니다. 같은 참여자가 여러 번 평가하면 참여자 수는 한 명이고 응답 수는 여러 건일 수 있습니다.
3. 각 점수의 평균과 1~5점 분포를 계산합니다.
4. 개선 의견은 의미가 비슷한 내용끼리 묶되 원문의 뜻을 바꾸지 않습니다.
5. 수정할 항목을 고른 뒤 변경 내용, 커밋, 재확인 결과를 [피드백 기록](피드백기록.md)에 남깁니다.

## 해석할 때 주의할 점

- 같은 사람이 다른 기기나 브라우저를 사용하면 새 참여 코드가 발급될 수 있습니다.
- 사이트 데이터를 지우면 새 참여 코드가 발급될 수 있습니다.
- 제출 ID는 참여자 수가 아니라 중복 제출 여부를 판단하는 값입니다.
- 개발자의 시험 응답과 자체 점검은 실제 사용자 피드백에 포함하지 않습니다.
- 앱의 일기 삭제 기능은 이미 제출된 Google Sheets 평가를 삭제하지 않습니다.
