## 감정 표현
- 코랄: 쾌적함 낮음·활력 높음 — 불안, 긴장.
- 옐로: 쾌적함 높음·활력 높음 — 신남, 설렘.
- 블루: 쾌적함 낮음·활력 낮음 — 지침, 슬픔.
- 세이지: 쾌적함 높음·활력 낮음 — 차분함, 편안함.
- 색과 텍스트·아이콘을 함께 사용한다. 사용자가 최종 선택한다.
- 기쁨을 무조건 고활력, 불안을 무조건 특정 좌표로 고정하지 않는다.
- 평온·중립 등 모델 출력에 없는 감정도 직접 선택할 수 있다.

## 공통 디자인과 상태
아이보리 배경, 네이비 본문, 라벤더 주요 버튼, 둥근 카드, 충분한 여백, 식물·창가·구름 캐릭터를 유지한다.
iOS·Android 모바일 브라우저와 데스크톱에서 확인한다. 네이티브 앱 설치·스토어 출시는 현재 확정 범위가 아니다.
큰 글자, 터치 영역, 색 대비, 모션 줄이기, 화면 낭독용 이름을 확인한다.
모든 데이터 화면에 최초 사용·로딩·성공·오류·기록 없음 상태를 준비한다.
UI 예시 데이터와 실제 사용자 기록은 구분한다.

### 추천 파이프라인

`KcELECTRA 감정 → 무드 미터에서 사용자 확정 → 동의한 선호·시간 반영 → 출처가 있는 추천 카드 → 앱 안에서 활동 수행`

현재 출처 카드 검색형 RAG와 생성형 코치 경로가 있으며, 연결 실패 시 규칙 기반 문장으로 전환한다. 위치 검색은 아직 구현하지 않았다. 향후 추가 시 브라우저 권한을 받은 순간에만 실행하며 좌표를 장기기억에 넣지 않는다.

### Agent 도구 계약

| 도구 | 책임 | 실패 시 동작 |
|---|---|---|
| `analyze_emotion` | KcELECTRA 분류와 스트레스 입력을 감정 좌표로 정리 | 입력 오류를 사용자에게 안내하고 원문을 보존 |
| `recommend_healing` | 감정·시간·선호에 맞춰 콘텐츠와 장소 추천 | 위치 권한이 없으면 비위치 추천으로 대체 |

추천 기능 중 현재 구현된 F20·F21·F22는 `recommend_healing` 결과 카드로 연결한다. F23·F24 위치 기능과 F25 카드별 추천 평가는 구현하지 않았다. 앱 전체 평가는 Agent와 분리된 `POST /api/app-rating` 경로로 Google Sheets에 저장한다. 모든 코치 흐름은 먼저 `analyze_emotion` 결과를 읽고 다음 도구를 선택한다.

현재 `/api/agent/coach`는 일기 요청 시 감정 분석·추천·근거 검색을 순서대로 실행한다. 출처 근거가 있는 생성형 코치 문장은 외부 AI 연결 상태에서 제공되고, 실패하면 규칙 기반 문장으로 돌아간다. 일반 코치 생성에는 일기 원문을 외부 AI로 보내지 않는다. 별도로 동의한 F29·F30 초안 요청에만 원문을 사용한다. 실행 추적에는 도구 이름만 포함하고 원문은 넣지 않는다.
